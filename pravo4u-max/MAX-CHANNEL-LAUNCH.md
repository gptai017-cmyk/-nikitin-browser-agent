## Действие владельца — создание публичного канала

По официальной инструкции https://dev.max.ru/docs/channels/create/ самозанятый с верифицированным профилем РФ может иметь один публичный бизнес-канал.
1. Авторизоваться в https://business.max.ru/ под владельцем текущего MAX-профиля Лекса.
2. «Каналы» → «Создать» → «Создать новый канал для бизнеса».
3. Продолжить в @business_channel_bot («Каналы в MAX для бизнеса»), подтвердить тот же номер, что у профиля.
4. Название: **ПРАВО4U | Под защитой**. Аватар: фирменный Лекс, без новых несогласованных логотипов. Описание ниже.
5. После создания открыть «Участники / Администраторы» и назначить бота @se14752741_bot администратором с правами **read_all_messages** и **write**.
6. Сохранить публичную ссылку канала и его chat_id; не пересылать токен бота. Настроить в Worker переменные MAX_CHANNEL_CHAT_ID и MAX_CHANNEL_URL. ТОЛЬКО после успешной реальной проверки участника можно включать обязательный вход через MAX.
7. Протестировать на двух пользовательских аккаунтах: подписан, не подписан; убедиться, что старые DOCX/покупки не заблокированы ошибочно.

Важно: MAX_API не создаёт канал бота из кода. Создание выполняется через зарегистрированный профиль владельца. В MAX нет подтверждённой общедоступной ссылки канала до фактического создания.
