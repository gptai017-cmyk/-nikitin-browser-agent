# ЛЕКС · Приём обращений «Земельного банка»

## Реализовано
- Встроенная форма на страницах участков, городов и сопровождения сделок.
- Имя, телефон, комментарий, отдельное согласие на обработку данных.
- Защита от повторного использования токена, проверка обязательных полей.
- После успешного сохранения на российском сервере клиент видит номер заявки (8 символов). **Это подтверждение на экране, не SMS и не письмо.**
- Первичная запись контактов — только в SQLite на сервере, физически находящемся в РФ; Cloudflare выдаёт анонимный краткоживущий токен.
- Фоновая синхронизация в Wrike каждые 60 секунд при наличии токена и папки: создаётся задача без ФИО, телефона, комментария и города. Связь с контактами — только в локальной российской БД по `wrike_task_id`.
- Если российский сервер не готов, встроенная форма не показывается: остаётся обращение через электронную почту.

## Статус запуска
**По умолчанию выключено.** Нельзя устанавливать `LAND_INTAKE_ENABLED=true` до юридической и технической проверки хостинга, согласия, реквизитов оператора и HTTPS.

## Требуется от владельца
1. Сервер/VPS с физическим размещением в России (IP и документ провайдера), домен HTTPS и доступ администратора. Не использовать Render, Cloudflare D1, зарубежные VPS или зарубежные базы для первичной записи персональных данных.
2. Полное наименование, адрес и контакт оператора персональных данных; проверить требования 152-ФЗ, уведомление Роскомнадзора и политику обработки.
3. API-токен Wrike и ID папки задач **передавать только через секреты сервера**, не в переписку и не в GitHub.
4. Назначить ответственного за ежедневную обработку и сроки ответа клиентам.

## Переменные российской службы
- `LAND_RU_HOST_ATTESTED=true` (только после подтверждения)
- `LAND_SIGNING_KEY` — один и тот же случайный секрет длиной 40+ символов в RU-сервере и Cloudflare Worker secret.
- `LAND_RU_DB_PATH=/var/lib/lex-land/requests.sqlite` — каталог и файл с правами 0700/0600.
- `PORT=8101` — только localhost за HTTPS reverse proxy.
- `LAND_WRIKE_PARENT_ID` — реальный ID папки Wrike REST API.
- `LAND_WRIKE_API_TOKEN` — серверный секрет Wrike.

Команда запуска (внутри российской системы с переменными окружения): `python3 land-intake-ru/server.py`. Перед сервисом требуется HTTPS reverse proxy и ограничения на входящие соединения. Нужны резервное копирование с шифрованием, удаление данных по сроку и операционный доступ к заявкам.

## Переменные Cloudflare Worker
- `LAND_INTAKE_ENABLED=true`
- `LAND_RU_STORAGE_CONFIRMED=true`
- `LAND_RU_PUBLIC_BASE=https://<российский-домен>/`
- `LAND_SIGNING_KEY` — Worker secret, совпадающий с RU.
- `LAND_PD_OPERATOR_NAME`, `LAND_PD_OPERATOR_CONTACT`, `LAND_PD_OPERATOR_ADDRESS`.

Только после полного подтверждения всех условий форма станет доступна; при отсутствии любого из них система остаётся в режиме email fallback.

- Проверка на iPhone внутри MAX. Только после этого запуск реального сбора данных.

## Что пока не включено
- Автоматическое SMS/email подтверждение: сейчас номер заявки показывается на экране.
- Приём реальных персональных данных: RU хост не подключён и не аттестован.
- Отправка имени/телефона в Wrike: сознательно запрещена до оценки трансграничной передачи.
- Автоматическая отправка агенту: сначала ручное распределение с подтверждением прав и доступности объектов.
