### Контроль качества до каждого поста
- Убедиться, что тема не повторяет последние материалы.
- Один конкретный пользователь и один практический результат; максимально простой язык.
- При юридических утверждениях дать основание; цену, сроки и цифры только при проверке.
- Человек должен получить пользу, даже если не подпишется на бот.
- Допустима одна аккуратная CTA к @advokat4ubot, не автоматическая реклама в каждом посте.
- Публикации отслеживать по GitHub Actions `SUCCESS` и telegram message_id; возможный `uncertain` не повторять.

### Как формируется прибыль
1. Бесплатный вход: понятный пост, чек-лист и доверие.
2. Переход по тематике: бот → бесплатный инструмент → платный конструктор при подходящем сценарии.
3. Сложный случай: остановка конструктора, предложение связаться с квалифицированным юристом/специалистом; согласие на передачу данных.
4. Только после значимой аудитории: партнёрские публикации, B2B-подписка «Документы для бизнеса» (ещё концепция), оценка CPA, CAC, повторной выручки.
5. Коммерческий пост: маркировка рекламы и требования законодательства о рекламе при применимости.
