# Издательский мост @yandzeen

## Статус
- Действующий GitHub Actions `TELEGRAM_BOT_TOKEN` проверен 13.10.2026. Он принадлежит `@nikitin_browser_agent_bot`.
- `@yandzeen` существует; `getChatMember` в проверке от 13.10.2026 вернул `CHANNEL_MEMBER_UNAVAILABLE`: у бота-публикатора нет подтверждённых прав.
- `@zen_sync_bot` успешно подключён владельцем к `@yandzeen` в автоматическом режиме. Однако перенос публикаций **от другого бота** в Дзен не подтверждён (боты Telegram обычно не получают сообщения от других ботов).
- Не изменяет ПРАВО4U, «Земельный банк», Cloudflare Worker, существующие браузерные маршруты или workflow bootstrap.

## Настройка (разовое действие владельца)
Telegram → @yandzeen → Изменить → Администраторы → Добавить `@nikitin_browser_agent_bot` → включить **Публикация сообщений** → Сохранить. Синхробот Дзена остаётся администратором.

Пароли, токены и коды входа в чат не передавать. Токен находится в GitHub Actions Secrets и не публикуется.

## Как работает
- `zen/content/calendar.json`: 8 исходных статей + 8 коротких уникальных Telegram-версий (<1500 символов).
- `.github/workflows/lesnoe-ozero-dzen.yml`: ежедневный запуск в 06:37 UTC = 09:37 Москва; также запуск при обновлении редакционного календаря и ручной запуск (по умолчанию dry-run).
- `zen/scripts/publish.mjs`: выбирает *самый ранний неопубликованный* материал с датой ≤ сегодня (Москва). При отсутствии прав пост пропускается и остаётся в очереди; после выдачи прав будет опубликован следующий день/при обновлении календаря.
- Перед отправкой проверяет `getMe`, `getChatMember` и право `can_post_messages`. Через Bot API отправляет одно сообщение за запуск.
- `zen/state/published.json`: хранит идентификаторы публикаций и ссылки `https://t.me/yandzeen/ID`, защищает от обычного дублирования.
- Публичный GitHub Actions обычного проекта без специальных платных интеграций. Но у GitHub, Telegram и Дзена есть технические квоты и ограничения.
- Автоматическая **генерация бесконечного количества новых материалов не реализована**: после использования восьми статей календарь нужно пополнять через ChatGPT/GitHub. Не обещать постоянный контент без пополнения.

## Контроль публикации
Сразу после первого выхода проверить `https://t.me/yandzeen/ID`. Отдельно открыть Дзен-студию и проверить перенос текста и форматирование. **Успех Telegram API не равен публикации в Дзене.** Если Дзен не видит сообщения от бота, выбрать пользовательскую сессию Telegram с надлежащей защитой или разрешённую публикацию в редакторе Дзена, а не отключать проверку.

## Важные особенности
- При редком сбое после отправки и до сохранения `published.json` возможна повторная отправка; контролировать журнал и ссылки.
- При отсутствии прав бот не публикует и не тратит Telegram-лимит.
- Не размещать неподтверждённые контакты, недостоверные обещания о подключении коммуникаций, доходности аренды или строительстве.
