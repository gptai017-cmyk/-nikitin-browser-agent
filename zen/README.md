# Мост «Лесное озеро» → Telegram → Дзен

Изолированная заготовка в ветке feature/lesnoe-ozero-dzen-bridge. Текущий продакшен браузерного агента не изменён.

## Что готово
- Три авторские статьи (2026-10-14, 2026-10-16, 2026-10-19), 2–2,5 тыс. символов каждая, в `zen/content/calendar.json`.
- Публикация в Telegram через официальный Bot API; планировщик GitHub Actions запускается ежедневно в 09:37 по Москве (06:37 UTC).
- Публикуются только даты из календаря; одна статья не публикуется повторно, если успех записан в `zen/state/published.json`.
- Dry-run по умолчанию в ручном запуске. Изменения в рабочем `main` отсутствуют.
- Публикация в Дзен требует отдельно настроенного штатного синхробота `@zen_sync_bot`. Успех Telegram **не** равен подтверждённой публикации Дзена.

## Доступы и настройка (без передачи паролей в чат)
1. Владелец входит в https://dzen.ru/editor и создаёт/выбирает канал «Лесное озеро | Земля и дома под Пензой».
2. В студии ищет «Кросспостинг / Telegram» и получает временный код. Открывает https://t.me/zen_sync_bot и привязывает публичный Telegram-канал, предоставляя боту нужные права в этом канале.
3. Для отдельного Telegram-канала «Лесное озеро» добавить администратора-публикатора с правом публикации. Существующие @zemlibank и @pravo4urus не перенастраивать без необходимости.
4. В GitHub Settings → Secrets and variables → Actions настроить `TELEGRAM_BOT_TOKEN` как Secret и `LEO_TELEGRAM_CHANNEL` как Variable (`@username` либо идентификатор канала). Не размещать токены в файлах или сообщениях.
5. Проверить разрешения Actions на запись Contents, выполнить ручной запуск с `dry_run=true` и затем контролируемую публикацию с `dry_run=false`.
6. После успешного теста перенести ветку в `main`, чтобы заработал календарь; проверить фактическую доставку в студии Дзена.
7. Добавить следующие оригинальные статьи в календарь; автогенерация новых текстов ChatGPT без платного API этим механизмом **не** предусмотрена.

## Важные ограничения
- Telegram Bot API ограничивает одно сообщение 4096 символами; намеренно используем 1500–4096 символов, чтобы пост потенциально стал статьёй в Дзене.
- Синхронизация может задерживаться, а оформление отличаться от редактора Дзена; нужно контролировать корректность переноса и правила платформы.
- GitHub Actions на стандартных раннерах публичного репозитория бесплатен на дату подготовки, но технические квоты и антиспам-ограничения Telegram/Дзена существуют.
- Публикации информативные, без гарантий роста стоимости участков, готовности коммуникаций или будущих доходов.
